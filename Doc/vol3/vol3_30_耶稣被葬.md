第 三十 课 : 30. 耶稣被葬 Yēsū bèi zàng (예수께서 장사되심)

## 本文 (본문)

到了晚上，有一个财主，名叫约瑟，是耶稣的门徒，这人去见彼拉多，求耶稣的身体。  
Dào le wǎnshang, yǒu yí ge cáizhǔ, míng jiào Yuēsè, shì Yēsū de méntú, zhè rén qù jiàn Bǐlāduō, qiú Yēsū de shēntǐ.  
저녁이 되어, 요셉이라 하는 한 부자가 있었는데 그는 예수의 제자였다. 그가 빌라도에게 가서 예수의 시신을 달라 청하였다.

彼拉多就吩咐给他。  
Bǐlāduō jiù fēnfù gěi tā.  
빌라도가 그렇게 주라 명하였다.

约瑟取了身体，用细麻布裹好，安放在自己的新坟墓里，就是他在磐石里凿的。  
Yuēsè qǔ le shēntǐ, yòng xì má bù guǒ hǎo, ānfàng zài zìjǐ de xīn fénmù lǐ, jiùshì tā zài pánshí lǐ záo de.  
요셉이 시신을 가져다 깨끗한 세마포로 싸서, 바위 속에 자신이 판 새 무덤에 안치하였다.

他又把大石头滚到墓门口就去了。  
Tā yòu bǎ dà shítou gǔn dào mù ménkǒu jiù qù le.  
또 큰 돌을 굴려 무덤 입구를 막고 떠났다.

第二天祭司长和法利赛人聚集来见彼拉多说："大人，我们记得耶稣还活着的时候曾说：三日后我要复活。"  
Dì èr tiān jìsīzhǎng hé fǎlìsàirén jùjí lái jiàn Bǐlāduō shuō: "Dàrén, wǒmen jìde Yēsū hái huó zhe de shíhou céng shuō: sān rì hòu wǒ yào fùhuó."  
이튿날 대제사장들과 바리새인들이 빌라도에게 와서 "주여, 예수께서 살아 계실 때 '사흘 후 부활하리라' 하셨습니다"라 하였다.

"因此，请吩咐人将坟墓把守妥当，直到第三日。"  
"Yīncǐ, qǐng fēnfù rén jiāng fénmù bǎshǒu tuǒdang, zhídào dì sān rì."  
"그러니 명령하여 사흘까지 무덤을 굳게 지키게 하소서."

"不然他的门徒来把他偷了去，就告诉百姓说：他从死里复活了。"  
"Bùrán tā de méntú lái bǎ tā tōu le qù, jiù gàosu bǎixìng shuō: tā cóng sǐ lǐ fùhuó le."  
"그렇지 않으면 제자들이 시신을 훔쳐가서 '그가 부활하셨다'고 백성에게 말할 것입니다."

彼拉多说："你们有看守的兵，去吧！尽你们所能把守妥当。" 他们就同兵丁去了。  
Bǐlāduō shuō: "Nǐmen yǒu kānshǒu de bīng, qù ba! Jìn nǐmen suǒ néng bǎshǒu tuǒdang." Tāmen jiù tóng bīngdīng qù le.  
빌라도가 "너희에게 경비병이 있으니 가서 힘대로 지키라"라 하니, 그들이 군병들과 함께 갔다.

## 主要词汇 (주요 단어)

### 1. 葬  /  zàng  /  [동사 (v.)]  /  장사하다, 매장하다
- 한자 풀이: 葬(장사 장) = 묻음  
- 例句: 把他葬在山上。  
- Pinyin: Bǎ tā zàng zài shān shàng.  
- 번역: 그를 산에 장사하다.

### 2. 细麻布  /  xì má bù  /  [명사 (n.)]  /  세마포, 고운 삼베
- 한자 풀이: 细(가늘 세) + 麻(삼 마) + 布(베 포) = 가는 삼베  
- 例句: 用细麻布裹尸体。  
- Pinyin: Yòng xì má bù guǒ shītǐ.  
- 번역: 세마포로 시신을 싸다.

### 3. 裹  /  guǒ  /  [동사 (v.)]  /  싸다, 감싸다
- 한자 풀이: 裹(쌀 과) = 둘러쌈  
- 例句: 把礼物裹起来。  
- Pinyin: Bǎ lǐwù guǒ qǐlái.  
- 번역: 선물을 포장하다.

### 4. 坟墓  /  fénmù  /  [명사 (n.)]  /  무덤
- 한자 풀이: 坟(무덤 분) + 墓(무덤 묘) = 무덤  
- 例句: 我们去坟墓扫墓。  
- Pinyin: Wǒmen qù fénmù sǎomù.  
- 번역: 우리는 무덤에 가서 성묘한다.

### 5. 凿  /  záo  /  [동사 (v.)]  /  (돌을) 파다, 뚫다
- 한자 풀이: 凿(뚫을 착) = 깎아 뚫음  
- 例句: 在山上凿洞。  
- Pinyin: Zài shān shàng záo dòng.  
- 번역: 산에 굴을 뚫다.

### 6. 把守  /  bǎshǒu  /  [동사 (v.)]  /  지키다, 방비하다
- 한자 풀이: 把(잡을 파) + 守(지킬 수) = 굳게 지킴  
- 例句: 兵把守城门。  
- Pinyin: Bīng bǎshǒu chéngmén.  
- 번역: 병사가 성문을 지킨다.

### 7. 妥当  /  tuǒdang  /  [형용사 (adj.)]  /  적당하다, 잘
- 한자 풀이: 妥(편안할 타) + 当(마땅 당) = 적당함  
- 例句: 把事情办妥当。  
- Pinyin: Bǎ shìqing bàn tuǒdang.  
- 번역: 일을 잘 처리하다.

### 8. 偷  /  tōu  /  [동사 (v.)]  /  훔치다
- 한자 풀이: 偷(훔칠 투) = 도둑질  
- 例句: 他偷了别人的东西。  
- Pinyin: Tā tōu le biérén de dōngxi.  
- 번역: 그가 남의 물건을 훔쳤다.

## 语法点 (어법 포인트)

### 1. 用 + 도구 + 동사 + 결과 : 도구로 ~하다
- 例句: 用细麻布裹好。  
- Pinyin: Yòng xì má bù guǒ hǎo.  
- 번역: 세마포로 잘 쌌다.

### 2. 把 + A + 滚/搬/抬 + 到 + 장소 : A를 ~로 굴리다
- 例句: 把大石头滚到墓门口。  
- Pinyin: Bǎ dà shítou gǔn dào mù ménkǒu.  
- 번역: 큰 돌을 무덤 입구로 굴렸다.

### 3. 将 + A + 把守 + 妥当 : A를 잘 지키다
- 例句: 将坟墓把守妥当。  
- Pinyin: Jiāng fénmù bǎshǒu tuǒdang.  
- 번역: 무덤을 잘 지키라.

### 4. 不然 + A 来 + 把 + B + 偷 + 了去 : 그렇지 않으면 A가 와서 B를 훔쳐 갈 것이다
- 例句: 不然门徒来把他偷了去。  
- Pinyin: Bùrán méntú lái bǎ tā tōu le qù.  
- 번역: 그렇지 않으면 제자들이 와서 그를 훔쳐갈 것이다.

## 传福音对话 (전도 회화)
**시나리오: 친구가 성묘·기일을 보내고 마음 무거울 때**

A: 你今天去给老人扫墓，我想跟你分享一件事。  
   Nǐ jīntiān qù gěi lǎorén sǎomù, wǒ xiǎng gēn nǐ fēnxiǎng yí jiàn shì.  
   오늘 성묘 다녀온다 했지. 나누고 싶은 게 있어.

B: 你说。  
   Nǐ shuō.  
   말해 봐.

A: 耶稣被埋只是暂时的安息，第三天就活过来了。圣经说'在主里睡了的人将来要醒过来'。  
   Yēsū bèi mái zhǐ shì zànshí de ānxī, dì sān tiān jiù huó guòlái le. Shèngjīng shuō 'zài zhǔ lǐ shuì le de rén jiānglái yào xǐng guòlái'.  
   예수님의 매장은 잠시의 안식이었고 사흘 만에 다시 사셨어. 성경은 '주 안에서 잠든 자는 깨어난다'고 해.

B: 这话挺安慰人。  
   Zhè huà tǐng ānwèi rén.  
   이 말, 정말 위로가 되네.

A: 咱们有再见的盼望。这是其他地方找不到的盼望。  
   Zánmen yǒu zàijiàn de pànwàng. Zhè shì qítā dìfang zhǎo bú dào de pànwàng.

## 实战场景 (선교 실전 시나리오)

### 상황 1: 耶稣被葬 / 安息的盼望 (대화 적용)

A: 人死了被埋了，故事就结束了吗？  
   Rén sǐ le bèi mái le, gùshi jiù jiéshù le ma?  
   사람이 죽어 묻히면 이야기는 끝인 거야?

B: 不是。耶稣被埋只是暂时的安息，他第三天就活过来了。  
   Bú shì. Yēsū bèi mái zhǐshì zànshí de ānxī, tā dì sān tiān jiù huó guòlái le.  
   아니. 예수님 매장은 잠시의 안식이고 사흘 만에 다시 사셨어.

A: 那对死了的家人也是这样吗？  
   Nà duì sǐ le de jiārén yěshì zhèyàng ma?  
   그럼 돌아가신 가족도 그래?

B: 圣经说，在主里睡了的人将来要醒过来。咱们还有再见的盼望。  
   Shèngjīng shuō, zài zhǔ li shuì le de rén jiānglái yào xǐng guòlái. Zánmen hái yǒu zàijiàn de pànwàng.  
   주 안에서 잠든 자는 다시 깨어난다고 해. 우리는 다시 만날 소망이 있어.


### 상황 2: 예상 질문

- Q: 真的有死后的世界吗？  
  Zhēn de yǒu sǐ hòu de shìjiè ma?  
  정말로 사후 세계가 있는 거야?  
  A: 耶稣自己从死里复活, 正是要告诉我们死亡不是终点。  
  Yēsū zìjǐ cóng sǐ lǐ fùhuó, zhèng shì yào gàosu wǒmen sǐwáng bú shì zhōngdiǎn.  
  예수님이 친히 죽음에서 살아나신 게 바로 죽음이 끝이 아니라는 걸 우리에게 알려주는 거야.
