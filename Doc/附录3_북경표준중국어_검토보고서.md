## 2. 공통적 문제 패턴

### 2.1 의미(意义) vs 의미(意思) 혼동
- 한국어 '의미'를 일관되게 `意义`로 번역하나, 일상 회화에서는 `有意思`가 자연스러움.  
- 修正 예: "挺有意义的" → "挺有意思的" (책 추천 받았을 때)  
- `有意义` = 철학적·심오한 의미, `有意思` = 재미있다, 흥미롭다.

### 2.2 문어체/신학용어가 일상 회화에 침투
- `体会`, `信实`, `失而复得`, `世上` 같은 단어들이 카페 잡담에서 등장.  
- 修正 例:  
  - `体会到` → `明白/知道`  
  - `信实地陪我` → `真心地陪我`  
  - `世上没有比 ~ 更可爱的` → `没有比 ~ 更可爱的`

### 2.3 儿化音 사용 부족
- 北京 표준어를 지향하나 儿化 빈도가 낮음.  
- 자주 빠지는 부분: 小狗(儿), 一会(儿), 今(儿), 味(儿), 这(儿)/那(儿).  
- 권장: 应用会话 한 회화당 2~3개 儿化 추가.

### 2.4 한국어 어순의 干渉
- `从他给的阳光...能感觉到` (한국어식 어순)  
- `让她体会到你真的很想要`  
- `谢谢你这么信实地陪我说话` (`信实` 자체가 신학 용어)

### 2.5 `挺~的` 과사용
- 거의 모든 회화에 등장 (挺新鲜的, 挺用心的, 挺有意义的, 挺难的, 挺不容易的, 挺多的).  
- 다양화 권장: `特别`, `真`, `蛮`, `还挺`, `怪~的`, `够~的`.

### 2.6 기독교 용어 일관성
- `转身` (회개) → `回转` / `回头` 으로 통일 권장.  
- `不舒服` (마음의 불편) → `心里不踏实` / `过意不去` / `堵得慌`.

### 2.7 `着急` 오용
- `太着急了` 가 "당황스럽다" 의미로 쓰였으나, 사실은 "걱정한다"의 상태.  
- 修正: `太急人了` / `够急人的`.

## 3. 시스템 권고사항

1. **应用会话 register 점검**: 文어 단어를 일상어로 일괄 교체 (体会→明白, 充满→满/堆满, 信实→真心, 意义→意思).  
2. **儿化 밀도 ↑**: 음식·일상사물·장소 맥락에서 2~3개씩 추가.  
3. **강조어 다양화**: `挺~的` 빈도 줄이고 `特别` / `真` / `蛮` / `还挺` / `怪~的` / `够~的` 로테이션.  
4. **기독교 용어 통일**: `回转`, `灵命成长`, 성경 인용 시 자연스러운 铺垫 사용.  
5. **북경 원어민 재 voicing**: 应用会话 섹션만 따로 원어민에게 다듬어 줄 것 권장. (本文/圣经引用/语法点은 적절히 정식 register 유지; 회화만 더 적극적으로 de-formalize 필요)
