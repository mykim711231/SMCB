# 拼写规则 (병음 표기 규칙)

같은 발음이라도 **어떤 위치에 오느냐**에 따라 한어병음(汉语拼音)의 표기가 달라집니다. 사전과 교재에서 자주 만나는 표기 규칙을 정리합니다.

> 발음(소리)은 같지만 **표기(쓰는 법)**가 바뀌는 규칙입니다. 외워 두면 사전 찾기·받아쓰기가 훨씬 수월해집니다.

---

## 1. i / u / ü가 음절 첫머리에 올 때

성모(자음) 없이 모음만으로 시작하는 음절은 **y / w**를 덧붙여 표기합니다.

### 1-1. `i`로 시작 → **`y`** 로 바꾸거나 덧붙임

| 원래 운모 | 표기 | 예시 |
|---|---|---|
| i | **yi** | yī 一 (하나) |
| ia | **ya** | yā 鸭 (오리) |
| ie | **ye** | yě 也 (~도) |
| iao | **yao** | yào 要 (원하다) |
| iou | **you** | yǒu 有 (있다) |
| ian | **yan** | yán 言 (말씀) |
| iang | **yang** | yàng 样 (모양) |
| in | **yin** | yīn 因 (원인) |
| ing | **ying** | yīng 应 (응당) |
| iong | **yong** | yòng 用 (쓰다) |

> 규칙: `i` → `y` 로 **교체** (i 단독은 yi, 다른 모음과 결합 시 i가 y로 바뀜)

### 1-2. `u`로 시작 → **`w`** 로 바꾸거나 덧붙임

| 원래 운모 | 표기 | 예시 |
|---|---|---|
| u | **wu** | wǔ 五 (다섯) |
| ua | **wa** | wā 蛙 (개구리) |
| uo | **wo** | wǒ 我 (나) |
| uai | **wai** | wài 外 (밖) |
| uei | **wei** | wèi 为 (위하여) |
| uan | **wan** | wán 玩 (놀다) |
| uang | **wang** | wáng 王 (왕) |
| uen | **wen** | wèn 问 (묻다) |
| ueng | **weng** | wēng 翁 (노인) |

> 규칙: `u` → `w` 로 **교체** (u 단독은 wu, 다른 모음과 결합 시 u가 w로 바뀜)

### 1-3. `ü`로 시작 → **`yu`** 로 표기 (두 점 생략)

| 원래 운모 | 표기 | 예시 | 음성 |
|---|---|---|---|
| ü | **yu** | yú 鱼 (물고기) | {{tts:鱼}} |
| üe | **yue** | yuè 月 (달) | {{tts:月}} |
| üan | **yuan** | yuǎn 远 (멀다) | {{tts:远}} |
| ün | **yun** | yùn 运 (운, 옮기다) | {{tts:运}} |

> 규칙: `ü` → `yu` 로 **교체**, 두 점은 **반드시 생략**

---

## 2. ü 두 점 생략 규칙

`ü`는 일부 성모 뒤에서 **두 점을 생략하고 u로 표기**합니다.

### 2-1. 두 점을 **생략**하는 경우 (j, q, x, y 뒤)

| 표기 | 실제 발음 | 예시 | 음성 |
|---|---|---|---|
| ju | jü | jù 句 (문장) | {{tts:句}} |
| qu | qü | qù 去 (가다) | {{tts:去}} |
| xu | xü | xū 需 (필요하다) | {{tts:需}} |
| yu | yü | yǔ 雨 (비) | {{tts:雨}} |

| 표기 | 실제 발음 | 예시 | 음성 |
|---|---|---|---|
| jue | jüe | juè 倔 (고집) | {{tts:倔}} |
| que | qüe | quē 缺 (부족하다) | {{tts:缺}} |
| xue | xüe | xué 学 (배우다) | {{tts:学}} |
| yue | yüe | yuè 月 (달) | {{tts:月}} |

> j·q·x·y 뒤에는 **u(=실제 u)** 가 올 수 없으므로 혼동되지 않습니다.

### 2-2. 두 점을 **유지**하는 경우 (n, l 뒤)

`n`과 `l` 뒤에는 `u`와 `ü`가 **모두 올 수 있어** 구분이 필요합니다.

| 표기 | 발음 | 음성 | 뜻 | 비교 |
|---|---|---|---|---|
| nu | 누 | {{tts:怒}} | 怒 nù (분노) | |
| **nü** | 뉘 | {{tts:女}} | 女 nǚ (여자) | nu와 구분 |
| lu | 루 | {{tts:路}} | 路 lù (길) | |
| **lü** | 뤼 | {{tts:绿}} | 绿 lǜ (녹색) | lu와 구분 |

> 한자 변환·입력 시 `nu`와 `nü`를 혼동하면 다른 글자가 나옵니다. 주의!

---

## 3. 운모 축약 표기 (iou, uei, uen)

성모와 결합할 때 가운데 모음이 **생략**되어 표기됩니다.

### 3-1. `iou` → `-iu` (성모 + iu)

| 표기 | 실제 발음 | 예시 | 음성 |
|---|---|---|---|
| liu | li-ou | liù 六 (여섯) | {{tts:六}} |
| jiu | ji-ou | jiǔ 九 (아홉) | {{tts:九}} |
| niu | ni-ou | niú 牛 (소) | {{tts:牛}} |
| qiu | qi-ou | qiū 秋 (가을) | {{tts:秋}} |
| xiu | xi-ou | xiū 休 (쉬다) | {{tts:休}} |

> 성모 없이 단독일 때는 **you** (`yǒu 有`) 로 표기 — 1-1 참고

### 3-2. `uei` → `-ui` (성모 + ui)

| 표기 | 실제 발음 | 예시 | 음성 |
|---|---|---|---|
| dui | du-ei | duì 对 (맞다) | {{tts:对}} |
| gui | gu-ei | guì 贵 (귀하다) | {{tts:贵}} |
| hui | hu-ei | huì 会 (~할 줄 안다) | {{tts:会}} |
| tui | tu-ei | tuī 推 (밀다) | {{tts:推}} |
| zui | zu-ei | zuì 最 (가장) | {{tts:最}} |

> 성모 없이 단독일 때는 **wei** (`wèi 为`) 로 표기

### 3-3. `uen` → `-un` (성모 + un)

| 표기 | 실제 발음 | 예시 | 음성 |
|---|---|---|---|
| dun | du-en | dùn 顿 (식사 양사) | {{tts:顿}} |
| lun | lu-en | lùn 论 (논하다) | {{tts:论}} |
| sun | su-en | sūn 孙 (손자) | {{tts:孙}} |
| tun | tu-en | tūn 吞 (삼키다) | {{tts:吞}} |
| zun | zu-en | zūn 尊 (높이다) | {{tts:尊}} |

> 성모 없이 단독일 때는 **wen** (`wèn 问`) 으로 표기

### 3-4. 한눈에 보기

| 원래 운모 | 성모와 결합 | 단독 표기 |
|---|---|---|
| iou | **-iu** (jiu, liu) | **you** |
| uei | **-ui** (dui, gui) | **wei** |
| uen | **-un** (dun, sun) | **wen** |

## 4. 성조 부호 위치 규칙 (再次)

성조 부호는 **주모음(主元音)** 위에 붙입니다. 우선순위:

```
a > o = e > i = u
```

### 우선순위 표

| 규칙 | 예시 |
|---|---|
| 1. `a`가 있으면 **a 위에** | hǎo, xiào, kuài, jiāo |
| 2. `a`가 없고 `o`가 있으면 **o 위에** | gǒu, duō, zhōu |
| 3. `a`도 `o`도 없고 `e`가 있으면 **e 위에** | wèi, gěi, xuě |
| 4. `i`와 `u`가 함께 오면 **뒤쪽** 위에 | liù (i+u → u), guī (u+i → i) |
| 5. 단독 `i`는 점을 빼고 표기 | nǐ, mǐ |
| 6. `ü`는 두 점과 함께 표기 | nǚ, lǜ |

> 외우기 팁: **"a가 일등, o·e가 이등, i·u는 함께면 뒤쪽"**

---

## 5. 음절 구분 부호 `'`

`a / o / e`로 시작하는 음절이 **다른 음절 뒤**에 오면, 경계를 분명히 하기 위해 **아포스트로피 `'`** 를 넣습니다.

| 잘못된 표기 | 올바른 표기 | 음성 | 뜻 |
|---|---|---|---|
| Xian | **Xī'ān** | {{tts:西安}} | 西安 (시안, 지명) |
| pingan | **píng'ān** | {{tts:平安}} | 平安 (평안) |
| Tiananmen | **Tiān'ānmén** | {{tts:天安门}} | 天安门 (천안문) |
| jian'ai | **jiān'ài** | {{tts:兼爱}} | 兼爱 (겸애) |
| nüer | **nǚ'ér** | {{tts:女儿}} | 女儿 (딸) |

### 왜 필요한가?

- `Xian` → **xi + an** 으로도, **xian** (한 음절) 으로도 읽힐 수 있음
- `xian` 한 음절 = 先, 现 등 / `xī'ān` 두 음절 = 西安
- `'`로 음절 경계를 표시하여 혼동 방지

## 6. 대문자·고유명사 표기

### 6-1. 인명·지명

- **성(姓)과 이름(名)을 띄어 쓰고, 각각 대문자로 시작**
- 이름이 두 글자여도 **붙여 씀**

| 한자 | 병음 | 비고 |
|---|---|---|
| 王刚 | **Wáng Gāng** | 성 + 이름 (1자) |
| 司马迁 | **Sīmǎ Qiān** | 성 (2자) + 이름 |
| 习近平 | **Xí Jìnpíng** | 성 + 이름 (2자, 붙여 씀) |
| 北京 | **Běijīng** | 지명은 붙여 씀 |
| 黑龙江 | **Hēilóngjiāng** | 지명은 붙여 씀 |

### 6-2. 문장 첫 글자

문장 첫 글자와 고유명사 첫 글자는 대문자로 씁니다.

| 예시 |
|---|
| **W**ǒ shì Hán**g**uó rén. (我是韩国人。 — 나는 한국인이다.) |
| **N**ǐ hǎo, **L**ǐ lǎoshī! (你好，李老师！— 안녕하세요, 이선생님!) |

## 7. 자주 헷갈리는 표기 정리

| 헷갈림 | 올바른 이해 |
|---|---|
| 왜 `一`은 `yī`로 쓰지 `i`라고 안 쓰나? | 음절 첫머리 `i` → **`yi`** 로 표기 |
| `ju`와 `zhu`의 차이? | **ju = jü** (위), **zhu = 권설 + 우** |
| `xu`는 "수"인가 "쉬"인가? | **xü** (위) — j/q/x 뒤의 u는 항상 ü |
| `liu`는 "리우"인가 "리오우"인가? | **iou의 축약** → 실제는 "리오우"에 가까움 |
| `wo`는 "워"인가 "우어"인가? | 성모 없는 `uo` → 실제는 "우어"이지만 보통 "워"로 들림 |
| `nü`를 `nu`로 쓰면? | **다른 글자**가 됨 (女 ≠ 怒) |

---

## 8. 표기 규칙 요약 카드

| 상황 | 표기 |
|---|---|
| 음절 첫 i | **yi** (yī 一) |
| 음절 첫 u | **wu** (wǔ 五) |
| 음절 첫 ü | **yu** (yú 鱼) |
| j/q/x/y + ü | **u** (ju, qu, xu, yu) |
| n/l + ü | **ü 유지** (nǚ, lǜ) |
| 성모 + iou | **-iu** (liù) |
| 성모 + uei | **-ui** (guì) |
| 성모 + uen | **-un** (dùn) |
| a/o/e 시작 음절이 뒤에 올 때 | **'** 삽입 (Xī'ān) |
| 인명 | 성 + 이름 (이름은 붙여 씀, 각각 대문자) |
| 지명 | **붙여 씀** (Běijīng) |

> 표기 규칙은 **소리는 같지만 형태만 달라지는 약속**입니다. 사전·교재의 표기가 헷갈릴 때 이 표를 참고하세요.
