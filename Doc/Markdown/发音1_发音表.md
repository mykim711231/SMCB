# 发音表 (발음표)

중국어 보통화(普通话)의 기본 발음은 **성모(声母)**, **운모(韵母)**, **성조(声调)**의 세 요소로 구성됩니다.

> 한 음절 = (성모) + 운모 + 성조
>
> 예) **mā** = m(성모) + a(운모) + 1성(声调)
> 예) **ǎi** = (성모 없음) + ai(운모) + 3성(声调)

---

## 1. 성조 (声调)

보통화에는 **4성 + 경성(輕聲)** 이 있습니다. 같은 음절이라도 성조가 다르면 뜻이 완전히 달라집니다.

| 성조 | 부호 | 음높이 변화 | 한국어 비유 | 예시 | 음성 |
|---|---|---|---|---|---|
| 1성 (제1성) | ā | **높고 평탄** (5→5) | "솔~" 하고 길게 끄는 느낌 | 妈 mā (엄마) | {{tts:妈}} |
| 2성 (제2성) | á | **낮→높이 올림** (3→5) | "왜?" 하고 되묻는 톤 | 麻 má (삼) | {{tts:麻}} |
| 3성 (제3성) | ǎ | **내렸다 살짝 올림** (2→1→4) | "흐~음…" 망설이는 톤 | 马 mǎ (말) | {{tts:马}} |
| 4성 (제4성) | à | **높→낮 빠르게 내림** (5→1) | "야!" 하고 호통치는 톤 | 骂 mà (꾸짖다) | {{tts:骂}} |
| 경성 (輕聲) | a | **짧고 가볍게** (앞 성조에 종속) | 끝 음절을 흘리듯 | 妈妈 māma (엄마) | {{tts:妈妈}} |

### 성조 표기 규칙

성조 부호는 운모의 **주모음(主母音)** 위에 붙입니다.

1. `a`가 있으면 `a` 위에 → hǎo, xiào
2. `a`가 없고 `o` 또는 `e`가 있으면 그 위에 → mèi, gǒu
3. `i`와 `u`가 함께 있으면 **뒤쪽** 모음에 → liù, guī
4. 단독 `i`는 점을 빼고 표기 → nǐ (ni → nǐ)
5. `ü` 위에는 두 점과 함께 표기 → nǚ, lǜ

## 2. 성모 (声母) - 자음 21개

성모는 음절의 **앞에 오는 자음**입니다. 입의 어느 부위에서 소리가 만들어지는지에 따라 7그룹으로 나뉩니다.

| 구분 | 무기음 | 유기음 | 비음·마찰음 | 발음 위치 |
|---|---|---|---|---|
| **순음 (脣音)** | b ㅂ | p ㅍ | m ㅁ / f ㅍ(f) | 입술 |
| **설첨음 (舌尖音)** | d ㄷ | t ㅌ | n ㄴ / l ㄹ | 혀끝 + 윗잇몸 |
| **설근음 (舌根音)** | g ㄱ | k ㅋ | h ㅎ | 혀뿌리 + 연구개 |
| **설면음 (舌面音)** | j ㅈ(i) | q ㅊ(i) | x ㅅ(i) | 혀 앞 + 경구개 |
| **권설음 (捲舌音)** | zh ㅈ | ch ㅊ | sh ㅅ / r | 혀끝 말아 올림 |
| **설치음 (舌齒音)** | z ㅉ | c ㅊ | s ㅆ | 혀끝 + 윗니 |

### 발음 요점

- **무기음 vs 유기음**: `b/p`, `d/t`, `g/k`, `j/q`, `zh/ch`, `z/c` 는 입에서 나오는 **공기의 세기** 차이입니다. 손바닥을 입 앞에 대고 연습하세요.
- **권설음 (zh, ch, sh, r)**: 혀끝을 **말아 올려** 입천장에 가까이 댑니다. 한국인이 가장 어려워하는 음.
- **설치음 (z, c, s)**: 혀끝을 **윗니 뒤**에 붙입니다. "츠츠츠"가 아닌 "쯔/츠/쓰"에 가깝습니다.
- **j, q, x**: 항상 `i` 또는 `ü`와만 결합합니다. (zh/ch/sh와 혼동 주의)
- **f**: 영어 f처럼 **윗니로 아랫입술을 살짝** 무는 소리. 한국어 ㅍ과 다름.
- **r**: 권설 + 유성음. 영어 r보다 혀가 더 안쪽으로 말림.

## 4. 한국인이 자주 틀리는 발음

| 잘못된 발음 | 올바른 발음 | 설명 |
|---|---|---|
| zh = ㅈ (한국식) | 혀끝을 **말아 올려** | 한국식 ㅈ은 j에 가깝다 |
| c = ㅆ | **유기음** ㅊ (강한 바람) | c는 z의 유기음 짝 |
| f = ㅍ | **윗니 + 아랫입술** | f와 p를 구분해야 함 |
| ü = 우 | **위** (입술은 u, 혀는 i) | nǚ를 "누"로 읽으면 안 됨 |
| 1성을 평탄하지 않게 | 한 음 그대로 **유지** | 한국어처럼 끝을 내리면 4성이 됨 |
| 3성을 끝까지 올림 | 단어 안에서는 **반3성** | 단독으로만 완전히 올림 |
