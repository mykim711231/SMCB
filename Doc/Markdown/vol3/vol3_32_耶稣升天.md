第 三十二 课 : 32. 耶稣升天 Yēsū shēngtiān (예수께서 승천하심)

## 本文 (본문)

这事以后，门徒中间有两个人往乡下去。  
Zhè shì yǐhòu, méntú zhōngjiān yǒu liǎng ge rén wǎng xiāngxià qù.  
이 일 후 제자들 중 두 사람이 시골로 가고 있었다.

走路的时候，耶稣变了形象向他们显现。  
Zǒulù de shíhou, Yēsū biàn le xíngxiàng xiàng tāmen xiǎnxiàn.  
길을 갈 때 예수께서 다른 모양으로 나타나셨다.

他们就去告诉其余的门徒，其余的门徒也是不信。  
Tāmen jiù qù gàosu qíyú de méntú, qíyú de méntú yěshì bú xìn.  
그들이 다른 제자들에게 알렸으나 그들도 믿지 않았다.

后来十一个门徒坐席的时候，耶稣向他们显现，责备他们不信，心里刚硬。  
Hòulái shíyī ge méntú zuòxí de shíhou, Yēsū xiàng tāmen xiǎnxiàn, zébèi tāmen bú xìn, xīnli gāngyìng.  
그 후 열한 제자가 식사할 때 예수께서 나타나, 그들의 믿지 않음과 마음의 완악함을 책망하셨다.

耶稣又对他们说："你们往普天下去传福音给万民听；信而受洗的必然得救，不信的必被定罪。"  
Yēsū yòu duì tāmen shuō: "Nǐmen wǎng pǔ tiānxià qù chuán fúyīn gěi wànmín tīng; xìn ér shòuxǐ de bìrán déjiù, bú xìn de bì bèi dìng zuì."  
또 "너희는 온 천하에 다니며 만민에게 복음을 전파하라. 믿고 세례 받는 자는 구원을 얻고, 믿지 않는 자는 정죄를 받으리라"라 하셨다.

"信的人必有神迹随着他们，就是奉我的名赶鬼，说方言，手按病人，病人就必好了。"  
"Xìn de rén bì yǒu shénjì suí zhe tāmen, jiùshì fèng wǒ de míng gǎn guǐ, shuō fāngyán, shǒu àn bìngrén, bìngrén jiù bì hǎo le."  
"믿는 자들에게는 표적이 따르리니, 내 이름으로 귀신을 쫓고 방언을 말하며, 병자에게 손을 얹으면 나으리라."

主耶稣和他们说完了话，后来被接到天上，坐在神的右边。  
Zhǔ Yēsū hé tāmen shuō wán le huà, hòulái bèi jiē dào tiānshàng, zuò zài Shén de yòubiān.  
주 예수께서 말씀을 마치신 후 하늘로 올리우셔서 하나님 우편에 앉으셨다.

门徒出去，到处宣传福音；主和他们同工，用神迹随着，证实所传的道。  
Méntú chūqù, dàochù xuānchuán fúyīn; zhǔ hé tāmen tóng gōng, yòng shénjì suí zhe, zhèngshí suǒ chuán de dào.  
제자들이 나가 곳곳에 복음을 전하니, 주께서 함께 일하시며 표적으로 따라 전한 말씀을 증명하셨다.

## 本文问题 (본문질문)

1. 耶稣升天前给门徒什么使命？  
   Yēsū shēngtiān qián gěi méntú shénme shǐmìng?  
   승천 전 명령은?

2. '凡我所吩咐你们的'指什么？  
   'Fán wǒ suǒ fēnfù nǐmen de' zhǐ shénme?  
   '분부한 모든 것'?

3. '我就常与你们同在'怎么实现？  
   'Wǒ jiù cháng yǔ nǐmen tóng zài' zěnme shíxiàn?  
   어떻게 함께하시는가?

4. 我们今天怎么完成大使命？  
   Wǒmen jīntiān zěnme wánchéng dà shǐmìng?  
   오늘 어떻게 사명을 완수하는가?

## 主要词汇 (주요 단어)

### 1. 升天  /  shēngtiān  /  [동사 (이합사)]  /  승천하다
- 한자 풀이: 升(오를 승) + 天(하늘 천) = 하늘로 오름  
- 例句: 耶稣升天后回到父那里。  
- Pinyin: Yēsū shēngtiān hòu huí dào fù nàli.  
- 번역: 예수께서 승천하신 후 아버지께 돌아가셨다.

### 2. 形象  /  xíngxiàng  /  [명사 (n.)]  /  형상, 모습
- 한자 풀이: 形(모양 형) + 象(코끼리 상/모양) = 모양  
- 例句: 神按自己的形象造人。  
- Pinyin: Shén àn zìjǐ de xíngxiàng zào rén.  
- 번역: 하나님이 자신의 형상대로 사람을 지으셨다.

### 3. 普天下  /  pǔ tiānxià  /  [명사 (n.)]  /  온 천하
- 한자 풀이: 普(넓을 보) + 天下(천하) = 온 세상  
- 例句: 把福音传到普天下。  
- Pinyin: Bǎ fúyīn chuán dào pǔ tiānxià.  
- 번역: 복음을 온 천하에 전하다.

### 4. 万民  /  wànmín  /  [명사 (n.)]  /  만민, 모든 사람
- 한자 풀이: 万(일만 만) + 民(백성 민) = 모든 백성  
- 例句: 神爱万民。  
- Pinyin: Shén ài wànmín.  
- 번역: 하나님은 모든 사람을 사랑하신다.

### 5. 得救  /  déjiù  /  [동사 (이합사)]  /  구원을 받다
- 한자 풀이: 得(얻을 득) + 救(구원할 구) = 구원을 얻음  
- 例句: 信耶稣得救。  
- Pinyin: Xìn Yēsū déjiù.  
- 번역: 예수를 믿어 구원을 받다.

### 6. 神迹  /  shénjì  /  [명사 (n.)]  /  기적, 표적
- 한자 풀이: 神(귀신 신) + 迹(자취 적) = 신의 자취  
- 例句: 神迹证明神的能力。  
- Pinyin: Shénjì zhèngmíng Shén de nénglì.  
- 번역: 기적은 하나님의 능력을 증명한다.

### 7. 方言  /  fāngyán  /  [명사 (n.)]  /  방언
- 한자 풀이: 方(모 방) + 言(말씀 언) = 다른 지방의 말  
- 例句: 中国有很多方言。  
- Pinyin: Zhōngguó yǒu hěn duō fāngyán.  
- 번역: 중국에는 방언이 많다.

### 8. 同工  /  tónggōng  /  [동사 (이합사)/명사]  /  함께 일하다, 동역자
- 한자 풀이: 同(같을 동) + 工(일 공) = 함께 일함  
- 例句: 主和我们同工。  
- Pinyin: Zhǔ hé wǒmen tónggōng.  
- 번역: 주께서 우리와 함께 일하신다.

## 语法点 (어법 포인트)

### 1. 信 + 而 + 受洗 + 的, 必然 + 得救 : 믿고 세례받는 자는 반드시 구원받는다
- 例句: 信而受洗的必然得救。  
- Pinyin: Xìn ér shòuxǐ de bìrán déjiù.  
- 번역: 믿고 세례 받는 자는 반드시 구원을 받는다.

### 2. 奉 + 명사 + 의 + 名 + 동사 : ~의 이름으로 ~하다
- 例句: 奉我的名赶鬼。  
- Pinyin: Fèng wǒ de míng gǎn guǐ.  
- 번역: 내 이름으로 귀신을 쫓다.

### 3. 被接到 + 장소 : ~에 영접되다, 데려가지다
- 例句: 耶稣被接到天上。  
- Pinyin: Yēsū bèi jiē dào tiānshàng.  
- 번역: 예수께서 하늘로 올리우셨다.

### 4. 用 + A + 随着, 证实 + B : A로 따라가며 B를 증명하다
- 例句: 用神迹随着，证实所传的道。  
- Pinyin: Yòng shénjì suí zhe, zhèngshí suǒ chuán de dào.  
- 번역: 표적으로 따라 전한 말씀을 증명하셨다.

## 应用会话 (응용 회화 - 일상)

A: 我朋友下个月要出国去美国工作了。  
   Wǒ péngyou xià ge yuè yào chū guó qù Měiguó gōngzuò le.  
   친구가 다음 달에 미국으로 일하러 떠나.

B: 挺好啊，去多久？  
   Tǐng hǎo a, qù duō jiǔ?  
   잘됐네, 얼마나 가?

A: 两三年吧。临走前我们好好儿聚一聚。  
   Liǎng sān nián ba. Lín zǒu qián wǒmen hǎohaor jù yi jù.  
   한 2~3년. 가기 전에 다 같이 잘 모이려고.

B: 人虽然走了，可联系不能断。  
   Rén suīrán zǒu le, kě liánxì bù néng duàn.  
   사람이 가도 연락은 끊기지 말아야지.

A: 就是说，常视频聊聊就好。  
   Jiùshì shuō, cháng shìpín liáoliao jiù hǎo.  
   그러게, 자주 영통하면 돼.

## 实战场景 (선교 실전 시나리오)

### 상황 1: 耶稣升天 / 大使命 (대화 적용)

A: 耶稣升天了，那他不就走了吗？  
   Yēsū shēngtiān le, nà tā bú jiù zǒu le ma?  
   예수님이 승천하셨으면 떠나신 거 아니야?

B: 肉身离开了，但他说：我就常与你们同在，直到世界的末了。  
   Ròushēn líkāi le, dàn tā shuō: wǒ jiù cháng yǔ nǐmen tóng zài, zhídào shìjiè de mòliǎo.  
   육신은 떠나셨지만 '세상 끝날까지 너희와 함께 있겠다'고 하셨어.

A: 怎么同在呢？  
   Zěnme tóng zài ne?  
   어떻게 함께하셔?

B: 圣灵住在信他的人里面。他还托付我们去传福音，告诉别人这好消息。  
   Shènglíng zhù zài xìn tā de rén lǐmiàn. Tā hái tuōfù wǒmen qù chuán fúyīn, gàosu biéren zhè hǎo xiāoxi.  
   성령이 믿는 자 안에 거하셔. 또 우리에게 복음 전하라 명령하셔서 좋은 소식을 알리라 하셨어.


### 상황 2: 예상 질문

- Q: 耶稣真的会再来吗？  
  Yēsū zhēn de huì zài lái ma?  
  예수님이 정말 다시 오실까?  
  A: 这是神亲口的应许。他怎样升天，也必怎样再来。你要等候他。  
  Zhè shì Shén qīnkǒu de yīngxǔ. Tā zěnyàng shēngtiān, yě bì zěnyàng zài lái. Nǐ yào děnghòu tā.  
  이는 하나님이 친히 주신 약속이시다. 그분이 승천하신 것 같이 반드시 다시 오실 것이다. 너는 그를 기다려라.
