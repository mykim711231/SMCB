第 二十四 课 : 24. 彼得认主为基督 Bǐdé rèn zhǔ wéi Jīdū (베드로가 주를 그리스도로 고백함)

## 本文 (본문)

有一天，耶稣问他的门徒说："人说我是谁呢？"  
Yǒu yì tiān, Yēsū wèn tā de méntú shuō: "Rén shuō wǒ shì shéi ne?"  
어느 날 예수께서 제자들에게 "사람들이 나를 누구라 하느냐?"라 물으셨다.

他们说："有人说是施洗的约翰，有人说是以利亚，又有人说是先知里的一位。"  
Tāmen shuō: "Yǒurén shuō shì shīxǐ de Yuēhàn, yǒurén shuō shì Yǐlìyà, yòu yǒurén shuō shì xiānzhī lǐ de yí wèi."  
그들이 "어떤 사람은 세례 요한, 엘리야, 선지자 중 하나라 합니다"라 하였다.

耶稣说："你们说我是谁？"  
Yēsū shuō: "Nǐmen shuō wǒ shì shéi?"  
예수께서 "너희는 나를 누구라 하느냐?"라 하셨다.

彼得回答说："你是基督，是永生神的儿子。"  
Bǐdé huídá shuō: "Nǐ shì Jīdū, shì yǒngshēng Shén de érzi."  
베드로가 "주는 그리스도시요, 살아 계신 하나님의 아들이십니다"라 하였다.

耶稣说："彼得，你是有福的；因为这不是人指示你的，乃是我在天上的父指示你的。"  
Yēsū shuō: "Bǐdé, nǐ shì yǒu fú de; yīnwèi zhè bú shì rén zhǐshì nǐ de, nǎishì wǒ zài tiānshàng de fù zhǐshì nǐ de."  
예수께서 "베드로야 너는 복이 있도다. 이를 알게 한 이는 사람이 아니요 하늘에 계신 내 아버지시라"라 하셨다.

从此，耶稣才指示门徒，他必须上耶路撒冷去，受长老、祭司长、文士许多的苦；并且被杀；第三日复活。  
Cóngcǐ, Yēsū cái zhǐshì méntú, tā bìxū shàng Yēlùsālěng qù, shòu zhǎnglǎo, jìsīzhǎng, wénshì xǔduō de kǔ; bìngqiě bèi shā; dì sān rì fùhuó.  
이때부터 예수께서 비로소 자기가 예루살렘에 올라가 장로들·대제사장들·서기관들에게 많은 고난을 받고 죽임 당하고 사흘 만에 다시 살아나실 것을 지시하셨다.

彼得就拉着他，劝他说："主啊！万不可如此；这事必不临到你身上。"  
Bǐdé jiù lā zhe tā, quàn tā shuō: "Zhǔ a! Wàn bù kě rúcǐ; zhè shì bì bù lín dào nǐ shēn shàng."  
베드로가 예수를 붙들고 "주여, 그리 마옵소서. 이 일이 결단코 주께 미치지 아니하리이다"라 하였다.

耶稣转过来，对彼得说："撒但，退我后边去吧！因为你不体贴神的意思，只体贴人的意思。"  
Yēsū zhuǎn guòlái, duì Bǐdé shuō: "Sādàn, tuì wǒ hòubiān qù ba! Yīnwèi nǐ bù tǐtiē Shén de yìsi, zhǐ tǐtiē rén de yìsi."  
예수께서 돌이키시며 "사탄아 내 뒤로 물러가라. 네가 하나님의 일을 생각지 아니하고 사람의 일을 생각하는도다"라 하셨다.

## 主要词汇 (주요 단어)

### 1. 基督  /  Jīdū  /  [명사 (n.)]  /  그리스도, 메시아
- 한자 풀이: 음역 (Christ → Jīdū)  
- 例句: 耶稣就是基督。  
- Pinyin: Yēsū jiùshì Jīdū.  
- 번역: 예수가 곧 그리스도이시다.

### 2. 永生  /  yǒngshēng  /  [명사 (n.)]  /  영생, 영원한 생명
- 한자 풀이: 永(길 영) + 生(살 생) = 영원한 생명  
- 例句: 信耶稣得永生。  
- Pinyin: Xìn Yēsū dé yǒngshēng.  
- 번역: 예수를 믿으면 영생을 얻는다.

### 3. 长老  /  zhǎnglǎo  /  [명사 (n.)]  /  장로
- 한자 풀이: 长(어른 장) + 老(늙을 로) = 연장자  
- 例句: 教会有几位长老。  
- Pinyin: Jiàohuì yǒu jǐ wèi zhǎnglǎo.  
- 번역: 교회에 장로 몇 분이 계신다.

### 4. 文士  /  wénshì  /  [명사 (n.)]  /  서기관, 학자
- 한자 풀이: 文(글월 문) + 士(선비 사) = 학식 있는 자  
- 例句: 文士读律法书。  
- Pinyin: Wénshì dú lǜfǎ shū.  
- 번역: 서기관이 율법서를 읽는다.

### 5. 撒但  /  Sādàn  /  [명사 (n.)]  /  사탄, 마귀
- 한자 풀이: 음역 (Satan)  
- 例句: 撒但是骗人的。  
- Pinyin: Sādàn shì piàn rén de.  
- 번역: 사탄은 사람을 속이는 자이다.

### 6. 体贴  /  tǐtiē  /  [동사 (v.)]  /  살피다, 배려하다
- 한자 풀이: 体(몸 체) + 贴(붙을 첩) = 체득함, 배려함  
- 例句: 妻子很体贴丈夫。  
- Pinyin: Qīzi hěn tǐtiē zhàngfu.  
- 번역: 아내가 남편을 매우 잘 살핀다.

### 7. 指示  /  zhǐshì  /  [동사 (v.)]  /  지시하다, 계시하다
- 한자 풀이: 指(가리킬 지) + 示(보일 시) = 가르쳐 보임  
- 例句: 神指示我们什么是真理。  
- Pinyin: Shén zhǐshì wǒmen shénme shì zhēnlǐ.  
- 번역: 하나님이 우리에게 진리가 무엇인지 보여주신다.

### 8. 临到  /  líndào  /  [동사 (v.)]  /  ~에 이르다, 임하다
- 한자 풀이: 临(임할 림) + 到(이를 도) = 도달함  
- 例句: 灾难临到他身上。  
- Pinyin: Zāinàn líndào tā shēn shàng.  
- 번역: 재난이 그에게 임했다.

## 语法点 (어법 포인트)

### 1. A 是有福的 ; 因为 ~ : A는 복이 있다, 왜냐하면 ~
- 例句: 彼得，你是有福的。  
- Pinyin: Bǐdé, nǐ shì yǒu fú de.  
- 번역: 베드로야, 너는 복이 있도다.

### 2. 不是 + A 指示 + 你, 乃是 + B 指示 : A가 가르친 게 아니라 B가 가르친 것이다
- 例句: 不是人指示你的，乃是我父指示你的。  
- Pinyin: Bú shì rén zhǐshì nǐ de, nǎishì wǒ fù zhǐshì nǐ de.  
- 번역: 사람이 알게 한 게 아니라 내 아버지께서 알게 하셨다.

### 3. 万不可 + 동사 : 결단코 ~해서는 안 된다
- 例句: 主啊，万不可如此。  
- Pinyin: Zhǔ a, wàn bù kě rúcǐ.  
- 번역: 주여, 결단코 그리 마옵소서.

### 4. 不 + A, 只 + B : A하지 않고 B만 하다
- 例句: 你不体贴神的意思，只体贴人的意思。  
- Pinyin: Nǐ bù tǐtiē Shén de yìsi, zhǐ tǐtiē rén de yìsi.  
- 번역: 너는 하나님 뜻이 아닌 사람 뜻만 생각한다.

A: 你觉得耶稣到底是谁？  
   Nǐ juéde Yēsū dàodǐ shì shéi?

B: 好人吧，挺有智慧的，做了不少好事。  
   Hǎorén ba, tǐng yǒu zhìhuì de, zuò le bù shǎo hǎo shì.  
   좋은 분이겠지, 지혜롭고 좋은 일도 많이 하셨고.

A: 我从前也这么想。后来读到圣经里耶稣问门徒"你们说我是谁？"彼得说"你是基督，是永生神的儿子。"  
   Wǒ cóngqián yě zhème xiǎng. Hòulái dú dào Shèngjīng lǐ Yēsū wèn méntú "Nǐmen shuō wǒ shì shéi?" Bǐdé shuō "Nǐ shì Jīdū, shì yǒngshēng Shén de érzi."  
   나도 그렇게 생각했어. 그런데 성경에서 예수님이 제자들에게 "너희는 나를 누구라 하느냐" 물으셨을 때 베드로가 "주는 그리스도시요 살아계신 하나님의 아들이십니다"라고 한 걸 읽었어.

B: 彼得挺有信心的。  
   Bǐdé tǐng yǒu xìnxīn de.

A: 耶稣说这不是人告诉他的，是神亲自指示他的。你也可以自己来问神——耶稣到底是谁。  
   Yēsū shuō zhè bú shì rén gàosu tā de, shì Shén qīnzì zhǐshì tā de. Nǐ yě kěyǐ zìjǐ lái wèn Shén——Yēsū dàodǐ shì shéi.  
   예수님은 이게 사람이 알려준 게 아니라 하나님이 직접 알게 하셨다고 말씀하셨어. 너도 직접 하나님께 물어볼 수 있어—예수님이 도대체 누구신지.

## 实战场景 (선교 실전 시나리오)

### 상황 1: 예수님은 누구신가 — 신앙 고백으로 이끄는 대화

A: 你对耶稣有什么看法？  
   Nǐ duì Yēsū yǒu shénme kànfǎ?  
   예수님에 대해 어떻게 생각해?

B: 我听过他不少事。你们基督徒说他是神的儿子，这什么意思？  
   Wǒ tīng guo tā bù shǎo shì. Nǐmen Jīdūtú shuō tā shì Shén de érzi, zhè shénme yìsi?  
   이야기는 많이 들었어. 기독교인들은 그분이 하나님의 아들이라는데, 무슨 뜻이야?

A: 这就是信仰最关键的问题。彼得当时回答说"你是基督，是永生神的儿子"——这句话改变了整个历史。  
   Zhè jiùshì xìnyǎng zuì guānjiàn de wèntí. Bǐdé dāngshí huídá shuō "Nǐ shì Jīdū, shì yǒngshēng Shén de érzi"——zhè jù huà gǎibiàn le zhěnggè lìshǐ.  
   그게 신앙의 가장 핵심적인 질문이야. 베드로가 그때 "주는 그리스도시요 살아계신 하나님의 아들이십니다"라고 답했는데, 이 고백이 온 역사를 바꿨어.

B: 他怎么能这么肯定？  
   Tā zěnme néng zhème kěndìng?  
   어떻게 그렇게 확신할 수 있었대?

A: 耶稣说不是人告诉他的，是神亲自启示的。你也可以自己寻求——读圣经，祷告，看神怎么让你认识耶稣。  
   Yēsū shuō bú shì rén gàosu tā de, shì Shén qīnzì qǐshì de. Nǐ yě kěyǐ zìjǐ xúnqiú——dú Shèngjīng, dǎogào, kàn Shén zěnme ràng nǐ rènshi Yēsū.  
   예수님 말씀으론 사람이 가르쳐준 게 아니라 하나님이 직접 계시하셨대. 너도 스스로 찾아봐—성경 읽고 기도하면서 하나님이 어떻게 예수님을 알게 하시는지.


### 상황 2: 예상 질문

- Q: 为什么说耶稣是"基督"？基督是什么意思？  
  Wèishénme shuō Yēsū shì "Jīdū"? Jīdū shì shénme yìsi?  
  왜 예수님을 "그리스도"라고 해? 그리스도가 무슨 뜻이야?  
  A: "基督"是希伯来文"弥赛亚"的意思，就是神应许要来拯救世人的救主。  
  "Jīdū" shì Xībólái wén "Mísàiyà" de yìsi, jiùshì Shén yīngxǔ yào lái zhěngjiù shìrén de Jiùzhǔ.  
  "그리스도"는 히브리어 "메시아"라는 뜻으로, 하나님이 세상을 구원하시기 위해 약속하신 구세주라는 의미야.
