# 主祷文 (주기도문)

예수님이 직접 가르치신 기도문(마태복음 6:9-13). 중국어 교회에서 가장 자주 함께 낭독되는 기도입니다.

## 全文 (전문)

{{verse:我们在天上的父：|Wǒmen zài tiānshàng de fù:|하늘에 계신 우리 아버지여,}}
{{verse:愿人都尊你的名为圣。|Yuàn rén dōu zūn nǐ de míng wéi shèng.|이름이 거룩히 여김을 받으시오며,}}
{{verse:愿你的国降临；|Yuàn nǐ de guó jiànglín;|나라가 임하시오며,}}
{{verse:愿你的旨意行在地上，如同行在天上。|Yuàn nǐ de zhǐyì xíng zài dìshàng, rútóng xíng zài tiānshàng.|뜻이 하늘에서 이루어진 것 같이 땅에서도 이루어지이다.}}
{{verse:我们日用的饮食，今日赐给我们。|Wǒmen rìyòng de yǐnshí, jīnrì cìgěi wǒmen.|오늘 우리에게 일용할 양식을 주시옵고,}}
{{verse:免我们的债，如同我们免了人的债。|Miǎn wǒmen de zhài, rútóng wǒmen miǎn le rén de zhài.|우리가 우리에게 죄 지은 자를 사하여 준 것 같이 우리 죄를 사하여 주시옵고,}}
{{verse:不叫我们遇见试探；|Bú jiào wǒmen yùjiàn shìtàn;|우리를 시험에 들게 하지 마시옵고,}}
{{verse:救我们脱离凶恶。|jiù wǒmen tuōlí xiōng'è.|다만 악에서 구하시옵소서.}}
{{verse:因为国度、权柄、荣耀，全是你的，|Yīnwèi guódù, quánbǐng, róngyào, quán shì nǐ de,|대개 나라와 권세와 영광이 아버지께}}
{{verse:直到永远。阿们。|zhídào yǒngyuǎn. Āmen.|영원히 있사옵나이다. 아멘.}}

## 핵심 어휘

{{vocab:天父|tiānfù|명사 (n.)|하늘 아버지, 하나님|天(하늘 천) + 父(아버지 부) → 하늘에 계신 아버지|天父爱我们每一个人。|Tiānfù ài wǒmen měi yí ge rén.|하늘 아버지께서는 우리 한 사람 한 사람을 사랑하신다.}}
{{vocab:尊为圣|zūn wéi shèng|동사구 (v.)|거룩히 여기다, 거룩하게 받들다|尊(높일 존) + 为(될 위) + 圣(성스러울 성) → 거룩하게 높여 받들다|愿人都尊你的名为圣。|Yuàn rén dōu zūn nǐ de míng wéi shèng.|사람들이 다 당신의 이름을 거룩히 여기게 하소서.}}
{{vocab:降临|jiànglín|동사 (v.)|임하다, 강림하다|降(내릴 강) + 临(임할 림) → 내려와 임하다|愿你的国降临。|Yuàn nǐ de guó jiànglín.|당신의 나라가 임하시오며.}}
{{vocab:旨意|zhǐyì|명사 (n.)|뜻, 의지, 의향|旨(뜻 지) + 意(뜻 의) → 깊은 뜻과 의지|愿你的旨意成就。|Yuàn nǐ de zhǐyì chéngjiù.|당신의 뜻이 이루어지이다.}}
{{vocab:饮食|yǐnshí|명사 (n.)|음식, 먹을 것|饮(마실 음) + 食(먹을 식) → 마시고 먹는 것|求你赐给我们日用的饮食。|Qiú nǐ cìgěi wǒmen rìyòng de yǐnshí.|우리에게 일용할 양식을 주시옵소서.}}
{{vocab:赐给|cìgěi|동사 (v.)|주시다, 하사하다|赐(줄 사) + 给(줄 급) → 윗사람이 아랫사람에게 주다|上帝赐给我们恩典。|Shàngdì cìgěi wǒmen ēndiǎn.|하나님께서 우리에게 은혜를 주신다.}}
{{vocab:债|zhài|명사 (n.)|빚, 부채 (여기서는 죄)|貝(조개 패) 의미부 → 갚아야 할 빚|免我们的债。|Miǎn wǒmen de zhài.|우리의 죄(빚)를 사하여 주옵소서.}}
{{vocab:免|miǎn|동사 (v.)|면제하다, 면하다, 사하다|免(면할 면) → 피하거나 없게 하다|求你免我们的债。|Qiú nǐ miǎn wǒmen de zhài.|우리의 죄를 사하여 주시기를 구합니다.}}
{{vocab:试探|shìtàn|명사/동사 (n./v.)|시험, 시련; 시험하다|试(시험할 시) + 探(찾을 탐) → 시험하여 알아보다|不叫我们遇见试探。|Bú jiào wǒmen yùjiàn shìtàn.|우리를 시험에 들게 하지 마옵시고.}}
{{vocab:脱离|tuōlí|동사 (v.)|벗어나다, 떠나다|脱(벗을 탈) + 离(떠날 리) → 벗어나 떠나다|愿主救我们脱离凶恶。|Yuàn zhǔ jiù wǒmen tuōlí xiōng'è.|주께서 우리를 악에서 구하소서.}}
{{vocab:凶恶|xiōng'è|명사/형용사 (n./adj.)|악, 흉악함; 사납고 악함|凶(흉할 흉) + 恶(악할 악) → 매우 사납고 악함|救我们脱离凶恶。|Jiù wǒmen tuōlí xiōng'è.|우리를 악에서 구하소서.}}
{{vocab:国度|guódù|명사 (n.)|나라, 왕국|国(나라 국) + 度(법도 도) → 나라의 영역과 다스림|上帝的国度永不衰败。|Shàngdì de guódù yǒng bù shuāibài.|하나님의 나라는 영원히 쇠하지 않는다.}}
{{vocab:权柄|quánbǐng|명사 (n.)|권세, 권위|权(권세 권) + 柄(자루 병) → 손에 쥔 권세|耶稣有赦罪的权柄。|Yēsū yǒu shèzuì de quánbǐng.|예수님은 죄를 사하는 권세가 있으시다.}}
{{vocab:荣耀|róngyào|명사 (n.)|영광, 영예|荣(영화 영) + 耀(빛날 요) → 빛나는 영광|愿一切荣耀归于上帝。|Yuàn yíqiè róngyào guī yú Shàngdì.|모든 영광이 하나님께 돌아가기를.}}
{{vocab:直到|zhídào|부사 (adv.)|~까지, ~에 이르도록|直(곧을 직) + 到(이를 도) → 곧장 이르기까지|主的爱直到永远。|Zhǔ de ài zhídào yǒngyuǎn.|주의 사랑은 영원에 이르신다.}}
{{vocab:永远|yǒngyuǎn|부사/명사 (adv./n.)|영원히, 영원|永(길 영) + 远(멀 원) → 끝없이 멀리|主永远与我们同在。|Zhǔ yǒngyuǎn yǔ wǒmen tóngzài.|주께서 영원히 우리와 함께 계신다.}}
{{vocab:阿们|Āmen|감탄사 (interj.)|아멘 (진실로 그렇습니다)|히브리어 "אָמֵן"의 음역|愿主祝福你们，阿们。|Yuàn zhǔ zhùfú nǐmen, Āmen.|주께서 너희에게 복 주시기를, 아멘.}}
