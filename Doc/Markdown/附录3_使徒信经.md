{{verse:升天，坐在全能父上帝的右边；|shēngtiān, zuò zài quánnéng fù Shàngdì de yòubiān;|하늘에 오르시어 전능하신 하나님 우편에 앉아 계시다가,}}

## 핵심 어휘

{{vocab:全能|quánnéng|형용사 (adj.)|전능하신, 모든 것을 할 수 있는|全(온전 전) + 能(능할 능) → 모든 것을 할 수 있음|上帝是全能的。|Shàngdì shì quánnéng de.|하나님은 전능하시다.}}
{{vocab:创造|chuàngzào|동사 (v.)|창조하다, 만들어 내다|创(처음 창) + 造(만들 조) → 처음으로 만들다|上帝创造了天地万物。|Shàngdì chuàngzào le tiāndì wànwù.|하나님께서 천지 만물을 창조하셨다.}}
{{vocab:独生子|dúshēngzǐ|명사 (n.)|외아들, 독생자|独(홀로 독) + 生(날 생) + 子(아들 자) → 단 하나뿐인 아들|耶稣是上帝的独生子。|Yēsū shì Shàngdì de dúshēngzǐ.|예수님은 하나님의 독생자이시다.}}
{{vocab:圣灵|Shènglíng|명사 (n.)|성령|圣(성스러울 성) + 灵(신령 령) → 거룩한 영|圣灵充满了门徒。|Shènglíng chōngmǎn le méntú.|성령께서 제자들을 충만케 하셨다.}}
{{vocab:感孕|gǎnyùn|동사 (v.)|잉태하다, 임신하다|感(느낄 감) + 孕(아이 밸 잉) → 임하여 잉태됨|马利亚因圣灵感孕。|Mǎlìyà yīn Shènglíng gǎnyùn.|마리아가 성령으로 잉태하셨다.}}
{{vocab:童贞女|tóngzhēnnǚ|명사 (n.)|동정녀, 처녀|童(아이 동) + 贞(곧을 정) + 女(여자 녀) → 순결한 처녀|马利亚是童贞女。|Mǎlìyà shì tóngzhēnnǚ.|마리아는 동정녀이시다.}}
{{vocab:受难|shòunàn|동사 (v.)|고난을 받다, 수난당하다|受(받을 수) + 难(어려울 난) → 어려움을 받다|耶稣为我们受难。|Yēsū wèi wǒmen shòunàn.|예수님은 우리를 위해 고난받으셨다.}}
{{vocab:钉十字架|dìng shízìjià|동사구 (v.)|십자가에 못 박히다|钉(못 정) + 十字架(십자가) → 십자가에 못 박음|耶稣被钉在十字架上。|Yēsū bèi dìng zài shízìjià shàng.|예수님은 십자가에 못 박히셨다.}}
{{vocab:埋葬|máizàng|동사 (v.)|장사되다, 매장하다|埋(묻을 매) + 葬(장사 장) → 묻어 장사 지내다|他们把耶稣埋葬在坟墓里。|Tāmen bǎ Yēsū máizàng zài fénmù lǐ.|그들은 예수님을 무덤에 장사 지냈다.}}
{{vocab:阴间|yīnjiān|명사 (n.)|음부, 죽음의 세계|阴(그늘 음) + 间(사이 간) → 어두운 곳, 죽은 자의 세계|耶稣降在阴间。|Yēsū jiàng zài yīnjiān.|예수님은 음부에 내려가셨다.}}
{{vocab:复活|fùhuó|동사 (v.)|부활하다, 다시 살아나다|复(다시 복) + 活(살 활) → 다시 살아남|耶稣第三日复活了。|Yēsū dì-sān rì fùhuó le.|예수님은 사흘 만에 부활하셨다.}}
{{vocab:升天|shēngtiān|동사 (v.)|승천하다, 하늘에 오르다|升(오를 승) + 天(하늘 천) → 하늘로 오름|耶稣升天后坐在父的右边。|Yēsū shēngtiān hòu zuò zài fù de yòubiān.|예수님은 승천하신 후 아버지 우편에 앉으셨다.}}
{{vocab:审判|shěnpàn|동사 (v.)|심판하다|审(살필 심) + 判(판단할 판) → 살펴 판단하다|主必审判活人和死人。|Zhǔ bì shěnpàn huórén hé sǐrén.|주님께서 산 자와 죽은 자를 심판하시리라.}}
{{vocab:教会|jiàohuì|명사 (n.)|교회|教(가르칠 교) + 会(모일 회) → 가르침으로 모인 공동체|我每周去教会做礼拜。|Wǒ měi zhōu qù jiàohuì zuò lǐbài.|나는 매주 교회에 가서 예배드린다.}}
{{vocab:圣徒|shèngtú|명사 (n.)|성도, 거룩한 무리|圣(성스러울 성) + 徒(무리 도) → 거룩한 무리|圣徒应当彼此相爱。|Shèngtú yīngdāng bǐcǐ xiāng'ài.|성도는 서로 사랑해야 한다.}}
{{vocab:赦免|shèmiǎn|동사 (v.)|사하여 주다, 용서하다|赦(용서할 사) + 免(면할 면) → 죄를 면해 주다|上帝赦免了我们的罪。|Shàngdì shèmiǎn le wǒmen de zuì.|하나님께서 우리의 죄를 사하셨다.}}
{{vocab:永生|yǒngshēng|명사 (n.)|영생, 영원한 생명|永(길 영) + 生(날 생) → 영원한 생명|信耶稣的人得永生。|Xìn Yēsū de rén dé yǒngshēng.|예수님을 믿는 사람은 영생을 얻는다.}}
{{vocab:阿们|Āmen|감탄사 (interj.)|아멘 (진실로 그렇습니다)|히브리어 "אָמֵן"의 음역|愿主祝福你们，阿们。|Yuàn zhǔ zhùfú nǐmen, Āmen.|주께서 너희에게 복 주시기를, 아멘.}}
